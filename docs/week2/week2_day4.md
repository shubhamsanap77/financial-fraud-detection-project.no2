## Implementation Details
- **Training Script**: `src/train_logistic_regression.py`
- **Model Architecture**:
  - Wrapped inside a Scikit-learn `Pipeline` to prevent data leakage:
    1. `StandardScaler()`: Standardizes unscaled numeric features (such as `amount`, `old_balance_orig`, etc.) based on training distribution statistics only.
    2. `LogisticRegression(C=1.0, solver='lbfgs', max_iter=1000, random_state=42, class_weight='balanced')`: Applies L2-regularized logistic regression.
- **Handling Class Imbalance**:
  - Fraud is extremely rare (~1.25% in train set).
  - Used `class_weight='balanced'` which assigns higher loss penalty weights to minority fraud instances inversely proportional to class frequencies ($w_1 = 40.0$, $w_0 = 0.506$), ensuring the classifier prioritizes fraud detection rather than collapsing to the majority class.
